# Быстрый старт

## 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

## 2. Установить и запустить Ollama

Скачать с https://ollama.com → установить → открыть **новый** терминал:

```bash
ollama serve
# В другом терминале:
ollama pull llama3.2:3b
```

> Альтернатива если мало RAM: `ollama pull gemma2:2b` (3.5 GB)

## 3. Запустить приложение

```bash
streamlit run app.py
```

Откроется браузер на http://localhost:8501

## 4. Использование

1. Загрузить PDF через боковую панель
2. Нажать **Индексировать** (займёт 5-20 мин первый раз)
3. Задавать вопросы в чате

---

## Потребление VRAM (RTX 3050)

| Этап                | VRAM       | Время         |
|---------------------|-----------|---------------|
| Индексация (VLM)    | ~1.6 GB   | 1-5 сек/картинка |
| Эмбеддинги (CPU)    | 0 GB      | быстро        |
| RAG запрос (Ollama) | ~2-3 GB   | 2-8 сек       |

> moondream2 загружается только во время индексации и выгружается сразу после.
> Ollama (llama3.2:3b) работает в отдельном процессе.

## Структура файлов

```
├── config.py           ← настройки моделей
├── ingest.py           ← обработка PDF → индекс
├── rag.py              ← движок поиска + генерации
├── app.py              ← Streamlit UI
├── requirements.txt
├── extracted_images/   ← извлечённые из PDF картинки
└── chroma_db/          ← векторная база данных
```
